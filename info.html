How to Connect

Follow these steps to join Skyland for the first time.

1
Download Minecraft Java

Make sure you have Minecraft Java Edition 1.21.11.

2
Open Multiplayer

From the main menu, click “Multiplayer”, then “Add Server”.

3
Enter Server Address

Type in the server address: play.mc-skyland.com

4
Click Join Server

Hit “Done” then double-click Skyland to join.
